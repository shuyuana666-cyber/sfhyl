# SFHYL 独立站后台使用教程

本教程按当前 SFHYL 后台菜单整理，面向日常内容维护、车辆发布和询盘跟进。

详细说明、官网客户操作和当前功能边界参阅 [平台功能与使用手册](user-manual.md)，另有 [Word 版](handbook/SFHYL平台功能与使用手册.docx)。

## 1. 登录与界面说明

- 正式站后台：[https://sfhyl.cn/admin/](https://sfhyl.cn/admin/)
- 本地开发后台：启动本地服务后打开 `http://127.0.0.1:5173/admin/`。
- 使用管理员账号登录。账号由站点超级管理员创建并分配角色；本教程不包含任何账号密码。
- 左侧菜单和页面按钮按账号权限显示。若菜单或操作按钮缺失，请联系超级管理员检查账号状态与角色权限。
- 修改表单后，点击页面上的“保存”“保存草稿”或“保存并发布”。离开仍有未保存内容的编辑页时，页面会提示确认。

后台菜单大致分为以下区域：

| 菜单 | 常见用途 |
| --- | --- |
| 数据概览 | 查看车辆、询盘、素材统计和近期操作 |
| 车辆管理 | 维护车辆、品牌、车系、车型、分类和标签 |
| 首页管理 | 配置首页轮播、模块、推荐车辆和优势内容 |
| 网站内容 | 编辑首页/关于我们内容、页面、导航、联系信息和 SEO |
| 素材管理 | 上传、整理、选择和维护图片/视频 |
| 客户管理 | 查看询盘、分配负责人、记录跟进和导出数据 |
| 权限管理 | 管理后台账号、角色和权限 |
| 系统管理 | 网站设置、模型配置、系统状态和日志 |

## 2. 数据概览

打开“数据概览”后，可在近 7 天、30 天、90 天和自定义日期范围间切换。自定义统计区间最多 366 天。

页面统计包括车辆总数、在售/已售/草稿、新车/二手车、今日/本周/本月询盘、未处理询盘，以及图片和视频素材数量。下方还可查看询盘与车辆发布趋势、询盘较多的车辆、最近操作和最近登录记录。

## 3. 素材管理

### 上传与整理素材

1. 打开“素材管理 → 图片库”或“视频库”。
2. 按用途进入文件夹；新建文件夹时，文件夹会建在当前目录下。浏览根目录时，新文件夹建在根目录。
3. 点击上传按钮选择文件，完成后可用文件名、类型、上传日期或文件夹筛选。
4. 素材卡片可预览图片/视频、编辑显示名称、移动到其他文件夹或复制 URL。编辑业务表单时，也可通过素材选择器直接挑选或上传素材。
5. 车辆媒体列表可拖动或用上下按钮调整顺序；最靠前的图片会作为车辆封面。

删除文件夹时，其中的素材和子文件夹会移动到上一级目录，素材文件本身、素材 ID 和已使用的图片地址会保留。移动素材也只调整文件夹归属，已有页面引用保持有效。

### 回收站与删除

- 素材库中的“彻底删除”和批量删除会删除原文件、缩略图、衍生文件及素材记录。被车辆、首页或页面引用的素材需先在相应内容中换成其他素材，再删除。
- 回收站用于查看历史归档素材，可恢复或永久删除。
- “素材管理 → 上传记录”记录上传成功、失败、耗时及失败原因。“全部清空”只清除上传记录，不会删除已上传素材。

## 4. 车辆管理

### 先维护车辆目录

打开“车辆管理 → 品牌管理、车系管理、车型管理、车辆分类或车辆标签”维护可复用目录项。添加车系时选择所属品牌；添加车型时还需选择所属车系。品牌可维护名称、国家/地区、Logo 和 SEO 信息；标签可设置颜色。

目录项在车辆资料中被引用时，删除会受到关联数据限制。停用不再使用的目录项，通常比删除更适合保留历史车辆资料。

### 新建并发布车辆

1. 上传车辆图片和视频，建议先整理好文件夹与显示名称。
2. 打开“车辆管理 → 新增车辆”，填写车辆名称、库存编号、类型、品牌、车系/车型、分类、标签、年份和所在地等信息。库存编号留空时会按日期自动生成。
3. 在“价格与参数”填写价格、货币、在售状态、里程、燃料、变速箱、驱动方式、颜色及其他技术参数。价格留空时，前台按询价方式展示。
4. 在“展示内容”填写摘要、车辆说明和核心亮点；核心亮点每行一项。“车辆配置（JSON）”需保持有效 JSON 格式。
5. 在“媒体素材”选择图片/视频并调整顺序。第一张图片是封面；发布前确认封面和图片清晰可用。
6. 点击“保存”保存车辆资料；点击“保存并发布”将车辆发布到官网。发布要求表单通过校验且车辆具备封面图片。
7. 返回列表后可预览车辆，并在官网车辆列表确认展示效果。

### 车辆状态与列表操作

车辆有两组独立状态：

| 状态类型 | 选项 | 作用 |
| --- | --- | --- |
| 发布状态 | 草稿、已发布、已下架、已归档 | 决定车辆内容的发布/下架状态 |
| 销售状态 | 在售、已预订、已售 | 表示库存销售进度 |

列表支持按关键词、品牌、车系、车型、分类、类型、推荐状态、发布状态、销售状态、年份和价格筛选；也可按时间、价格或年份排序。选中多辆车后，可批量发布、下架、推荐/取消推荐、标记已售、恢复在售、恢复或删除；有导出权限时可下载 CSV。

“删除车辆”会将记录移入回收状态，不等同于清除历史数据。列表筛选中的“回收站”可查找记录并恢复。

## 5. 首页管理

### 轮播图

在“首页管理 → 轮播图”新增或编辑首页 Banner：填写唯一标识、中英文标题/副标题、PC 图片、可选的移动端图片、按钮文字、跳转链接和打开方式，并设置状态及开始/结束时间。只有启用且在有效期内的 Banner 会公开展示；保存后到官网首页核对图片、文字与链接。

### 首页模块与推荐车辆

- “首页模块”可查看模块标题、显示数量和显示状态；按页面提供的上下箭头调整顺序。点击“配置”可编辑标题、副标题、背景图、显示数量和显示/隐藏状态。
- “品牌展示”“首页视频”“公司简介”“行动按钮”是首页模块的分类管理入口；“优势图标”可新增、编辑、排序或隐藏优势内容，支持中文、英文和俄文标题/说明。
- “推荐车辆”上方会显示官网当前实际展示的车辆和来源。下方“推荐配置”可以添加/编辑车辆、设置推荐标签、有效期、启用状态和顺序。
- 推荐车辆通常按“推荐配置 → 车辆列表中的推荐标记 → 自动展示已发布车辆”的顺序选取。若首页没有预期车辆，先检查推荐模块是否显示、车辆是否已发布、推荐是否启用以及有效期是否覆盖当前时间。

模块配置中的 JSON 字段供特定展示配置使用。日常运营通常只需调整标题、图片、数量、排序和显示状态；修改 JSON 前应先确认字段格式与目标效果。

### 首页展示内容

“网站内容 → 首页展示内容”提供顶部轮播、关于我们、运输与交付、员工、视频、快捷导航、地点和自定义模块等内容区。此配置供首页/关于我们相关展示使用；顶部专题 Banner 及其有效期、按钮链接在“首页管理 → 轮播图”维护。

每个内容区可编辑多语言标题和说明、选择素材、控制显示状态、添加/移除条目并调整顺序。编辑器提供“保存草稿”和“保存并发布”。当前使用同一条内容记录，已发布内容点击“保存草稿”会更新内容并保留发布状态，修改可能直接同步官网。大改动先在本地准备，修改后分别检查官网首页与“关于我们”。首页首屏优先使用有效 Banner；“关于我们”读取此处顶部轮播，首页无有效 Banner 时回退使用。

## 6. 网站内容

### 页面管理

1. 打开“网站内容 → 页面管理”，点击“新增页面”。
2. 填写中文标题、摘要、正文 HTML；可选择分享图片并补充 SEO 标题、关键词和描述。
3. 新建时点击“保存草稿”保存待编辑内容，或点击“保存并发布”更新公开接口数据。已有发布记录再次保存通常保留原状态；当前前端没有通用页面路由，新增普通页面需技术人员接入展示入口。
4. 回到列表可按标题、发布状态或回收站筛选，编辑已存在页面，发布草稿，或恢复回收站中的页面。

### 导航菜单

在“网站内容 → 导航菜单”新增或编辑菜单项，填写唯一标识、中文/英文名称、可选俄文名称、站内路径或外部链接、打开方式、图标、父级菜单及显示状态。用排序按钮调整同一级菜单的顺序；保存后查看官网导航及链接落点。

### 联系方式、社交媒体、SEO 与页脚

进入“网站内容”下对应项目，或在“系统管理 → 网站设置”使用左侧设置分组：

- **联系方式**：电话、WhatsApp、微信、邮箱、营业时间和公司地址。
- **社交媒体**：WhatsApp、Facebook、Instagram、YouTube、LinkedIn、TikTok、X/Twitter 和 VK 链接。WhatsApp 链接留空时，官网会尝试从联系方式中的号码生成链接。
- **SEO 设置**：站点默认标题、关键词和描述。单个页面/品牌有独立 SEO 内容时，优先维护对应内容记录。
- **页脚信息**：版权文字及备案信息。
- **基础信息/品牌标识**：多语言站点名称、公司名称、默认语言和货币，以及网站 Logo、移动端 Logo、Favicon 和分享图片。

每个设置分组单独点击“保存”。设置保存后由官网公开接口读取；检查官网时可刷新页面并核对联系方式、页眉、页脚和浏览器图标。

## 7. 客户管理与询盘跟进

“客户管理”中的“询价记录”“联系留言”和“WhatsApp 咨询”使用同一套询盘列表，并按来源预设筛选。可按客户姓名、电话、邮箱、公司、状态、来源、负责人和日期查询，也可导出 CSV。

建议按以下步骤处理新询盘：

1. 打开询盘详情，核对客户联系方式、留言、来源和意向车辆。
2. 分配负责人，并在每次沟通后添加“内部备注”，记录沟通结果和下一步安排。内部备注仅供后台跟进使用。
3. 按处理进度更新状态：新询盘 → 已联系 → 跟进中 → 已报价 → 已成交；最终未成交可标记已流失，无效线索可标记无效。
4. 确认记录已完成后再使用“归档”。

可批量更新状态或分配负责人。“客户备注”页面可跨询盘查询内部跟进记录。建议定期检查后台列表；询盘通知通道是否完成部署配置，以系统运行配置为准，后台询盘记录作为处理依据。

## 8. 权限管理

- **管理员**：新增后台账号时填写用户名、邮箱、显示名称、初始密码和角色。初始密码至少 12 位，并包含大写字母、小写字母和数字。编辑账号可调整邮箱、显示名称、状态与角色。
- **角色权限**：新增角色时设置编码、中英文名称、状态及权限；权限按业务模块分组，可逐项勾选或按模块全选。角色调整后，关联账号的菜单和按钮权限随之变化。
- **权限列表**：查看系统登记的权限码。

系统角色与最后一个有效超级管理员受保护。权限建议按岗位所需范围分配；调整前先确认至少保留可管理后台的账号。

## 9. 系统管理

- **网站设置**：维护网站基础信息、品牌标识、联系信息、社交媒体、SEO 默认值、页脚和功能开关。
- **功能开关 → 维护模式**：启用后官网会显示维护提示页。仅在计划维护时操作；完成维护后关闭开关并检查官网。
- **API 模型配置**：查看/设置翻译模型协议、Base URL、API Key 和模型 ID。密钥输入框留空会保留现有密钥；保存后密钥状态只显示是否已配置。
- **文件存储、邮件设置**：查看当前存储驱动、公开地址、凭据配置状态和 SMTP 状态。这些页面以状态查看为主；需要改动部署参数时联系负责服务器配置的管理员。
- **操作日志、登录日志、系统日志**：按时间、账号、操作或结果查找记录，便于审计和定位问题。
- **系统信息**：查看当前服务信息。

## 10. 常见问题

### 保存后官网没有变化

先确认操作成功提示；页面类内容要确认已发布，轮播图、首页模块和推荐车辆还需检查是否启用及有效期。随后刷新官网对应页面，并分别检查桌面端和移动端图片。如果仍未更新，可查看“系统管理 → 操作日志”确认修改记录。

### 素材删除失败

素材仍被车辆、首页或页面引用时，系统会阻止永久删除。先到引用内容中换用其他素材并保存，再返回素材库处理旧文件。

### 看不到某项菜单或按钮

菜单和按钮受账号角色及权限控制。请管理员在“权限管理 → 管理员 / 角色权限”确认账号状态与权限配置。

### 登录失败或账号被锁定

确认用户名/邮箱及密码输入无误。连续登录失败可能触发临时锁定；联系超级管理员核对账号状态与登录日志。
