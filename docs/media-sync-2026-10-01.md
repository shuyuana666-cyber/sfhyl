## 后续同步流程

1. `scripts/export-local-content.cjs` 只读导出公开页面配置、本地活动素材及车辆资料；兼容本地文件存储和 MinIO，缺失的页面引用文件会中止导出。
2. `scripts/sync-local-content.py` 经已信任的 SSH 主机上传，支持断点续传。连接信息从环境变量读取，文件按 SHA-256 命名；需安装 Python `paramiko`。
3. 将 `scripts/import-local-content.cjs` 挂载到 API 镜像的 `/app/` 下运行，将材料目录挂载到 `/sync`。导入前核验全部文件哈希；导入后确认页面、车辆和素材引用。
4. `scripts/purge-replaced-media.cjs` 在核验完成后清理旧媒体。若仍有活动车辆引用旧封面，则中止清理。确认目标发布目录后再清理旧静态媒体。
5. 从公网验证图片、视频 Range 请求、后台素材库和旧资源 404。迁移日期前缀需要按每次迁移调整，避免覆盖正在使用的对象。

迁移材料只用于运维，不增加网站公开 API 或数据库字段；后台后续上传、移动、删除仍使用现有功能。
