# Default vehicle brand icons

The homepage default catalogue uses local image files so the site works without
an external image service. Administrators can replace or clear each image under
`/admin/vehicles/brands`.

- 17 icons (all except Tank): [VehicleSpecs brand logos](https://github.com/vehiclespecs/brand-logos), retrieved 2026-09-29. The repository metadata is MIT licensed; the logos remain trademarks of their respective owners.
- Tank icon: [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Tank_(Great_Wall_Motor_brand)_logo,_Chinese_and_Russian_market.svg), retrieved 2026-09-29. The Commons file page identifies the image as a public domain text logo and notes its trademark status.

These icons identify the manufacturers and do not imply endorsement or affiliation.
